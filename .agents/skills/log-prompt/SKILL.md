# log-prompt

จงอ่านค่าตัวแปร `PROMPT_LOG_FILE_PATH` จากไฟล์ `.env` ในโปรเจกต์นี้ เพื่อระบุ Path ของไฟล์ Log (ถ้าไม่มีให้ใช้ค่าเริ่มต้นเป็น `prompt-experiments.md`) และสร้างหรือปรับปรุงไฟล์ดังกล่าว โดยใช้โครงสร้างตาราง Markdown ใหม่ดังนี้:

| วันที่เวลา | AI Model | Session ID | Prompt | Results | Remark |
| :--- | :--- | :--- | :--- | :--- | :--- |

เงื่อนไขและขั้นตอนปฏิบัติ (Workflow):
1. ต่อจากนี้ ทุกครั้งที่ฉันพิมพ์คำสั่งสั้นๆ ว่า `/log` ให้เธอสแกนประวัติการคุยล่าสุดใน Session นี้ที่ยังไม่เคยถูกบันทึก
2. สรุปข้อมูลดิบจากการคุยรอบนั้นลงตาราง โดยในช่อง "วันที่เวลา" ให้ใช้เวลาปัจจุบันที่เธอกำลังบันทึกข้อมูล
3. นำแถวข้อมูลที่สรุปได้ไปเขียนต่อท้าย (Append) ในไฟล์ Log ที่ระบุ ทันที
4. หลังจากพิมพ์ลงไฟล์เสร็จ ให้พิมพ์ตอบกลับมาในแชทแค่เฉพาะแถวตาราง (Markdown Row) ที่เธอเพิ่งบันทึกไปเท่านั้น "ห้ามทักทาย ห้ามอธิบาย หรือพ่นข้อความอื่นใดเพิ่มเติม" เพื่อประหยัด Context

หากเข้าใจโครงสร้างและเงื่อนไขใหม่นี้แล้ว ให้จัดการไฟล์ Log ทันที และตอบกลับสั้นๆ ว่า "System Ready"
