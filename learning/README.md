## Directory จะเป็นการรวบรวมวิธีการเรียนรู้ของการใช้ Claudeให้ได้ผลลัพธ์อย่างที่ใจต้องการภายใน Prompt เดียว

prompt สำหรับการการรู้ว่าเราพลาดตรงไหนในการคุย session นี้
```
ช่วยทำ retrospective ของบทสนทนานี้ทั้งหมด โดยมองย้อนกลับอย่างตรงไปตรงมา
เป้าหมายคือให้ฉันเรียนรู้ว่าจะสื่อสารให้จบในรอบเดียวได้ยังไง

เริ่มด้วยส่วนนี้ก่อน:

0. [สรุปงานนี้สั้นๆ]
   - 2-3 ประโยค ว่า session นี้ฉันให้คุณช่วยทำอะไร เป้าหมายหลักคืออะไร
   - ตอนจบ งานสำเร็จระดับไหน (เสร็จ / เสร็จบางส่วน / ยังค้าง)

แล้วค่อยวิเคราะห์ต่อ 4 ส่วนนี้:

1. [จุดที่ฉันสื่อสารไม่ชัด / ให้ข้อมูลไม่ครบ]
   - ระบุข้อความจริงของฉันที่กำกวมหรือขาด context
   - บอกว่าตอนนั้นคุณ "เดา" อะไรไป เพราะข้อมูลไม่พอ

2. [จุดที่เข้าใจกันคนละอย่าง]
   - จุดที่คุณตีความไม่ตรงกับที่ฉันตั้งใจ
   - ฉันรู้ได้ตอนไหนว่าคลาดกัน (ข้อความไหนที่ฉันต้องทักกลับ)

3. [แยกรอบ: rework vs scope ใหม่]
   - แต่ละรอบที่วนกลับมา เป็นการ "แก้ของเดิมที่พลาด" หรือ "ฉันเพิ่ม/เปลี่ยนเป้า"
   - อันไหนกันได้ อันไหนเป็นธรรมชาติของงาน

4. [รอบหน้าทำยังไง — ของจริง ไม่ใช่หลักการลอยๆ]
   - สำหรับแต่ละจุดในข้อ 1-2 เขียนให้ดูว่า "ถ้าฉันพิมพ์แบบนี้ตั้งแต่แรกจะดีกว่ายังไง"
   - สุดท้าย เขียน "ข้อความเปิด session" ในอุดมคติที่ฉันควรพิมพ์ตอนเริ่ม ให้พร้อมก๊อปไปใช้ครั้งหน้า

ขอความซื่อสัตย์ ระบุข้อความจริงในบทสนทนาเป็นหลักฐาน ไม่ต้องถนอมน้ำใจ
และบอกด้วยว่าจุดไหนเป็นข้อจำกัดของคุณเอง (เช่น มองไม่เห็นหน้าจอ) ที่ไม่ใช่ความผิดฉัน
```
